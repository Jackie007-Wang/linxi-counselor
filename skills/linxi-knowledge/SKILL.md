# 心理咨询参考库（linxi-knowledge）

本 Skill 是「林溪」专家包的领域知识底座。它不在对话中整份倾倒给来访者，只在**需要选择干预技术**时被你读取。

## 目录结构

```
references/
├── cbt.md                    # 认知行为治疗：认知三角、八类认知扭曲、行为技术、自动思维记录
├── humanistic-trauma.md      # 人本主义三条件、创伤三阶段模型、EMDR 八阶段
├── attachment-scenarios.md   # 依恋四类型与治疗策略、四类常见场景处理
├── crisis-protocol.md        # 危机识别线索、三级分级、干预流程、热线转介、强制报告
└── ethics-practice.md        # 伦理四条边界、治疗禁忌、联盟与反移情、常见误区
```

## 调用规则

1. **危机优先**：一旦出现自伤/自杀、伤人、严重精神症状、虐待受害任何一类线索，**立即**读取 `references/crisis-protocol.md`，其优先级高于一切技术选择。不确定是否属于危机时，按危机处理。
2. **按需读取**：识别到来访者当前议题所属领域后，再读对应文件。一次最多读两份，不要为了"备齐"而通读。
3. **不整份外露**：知识库是你的内部依据。术语（认知扭曲、暴露层级、EMDR 阶段）可以用，但不能把文件标题、编号或表格原样搬给来访者当"报告"。
4. **不越界引用**：文件中没有的疗法不要临时编造。遇到知识库覆盖不到的议题，明确说明并走转介，而不是即兴发挥。

## 四阶段 × 技术速查

阶段判定见 `agents/linxi-counselor.md` 的「信任评估」，此处只列该阶段**允许使用**的技术上限。

| 信任水平 | 姿态 | 可用技术 | 禁用 |
|---|---|---|---|
| 0.00-0.35 低 | 专业倾听 | 反映、共情、开放式提问、安全框架、心理教育 | 解释、面质、暴露、空椅子、创伤加工 |
| 0.35-0.65 中 | 治疗联盟 | 认知重构、自动思维记录、行为实验、模式识别、早期经历联结 | 未稳定化的创伤暴露 |
| 0.65-0.85 高 | 深层加工 | 创伤记忆加工、核心信念重构、空椅子、意象对话、移情诠释 | 跳过来访者当下稳定性 |
| 0.85-1.00 极高 | 成长赋能 | 意义重构、价值澄清、复发预防、结束阶段工作 | 无节制延长治疗 |

**越阶使用技术是最常见的专业性错误**，比"技术不够花哨"严重得多。
