# 依恋模式与常见场景处理

## 一、依恋四类型

依恋类型不是人格标签，是**在关系里习得的生存策略**。不要向来访者宣布"你是回避型"——那会变成新的自我定义，而不是理解。

| 类型 | 核心特征 | 关系中的表现 | 治疗策略 | 常见失误 |
|---|---|---|---|---|
| 安全型 | 能信任，也能独处 | 求助与自主都自然 | 支持探索，适度挑战 | 误以为"没什么可做" |
| 焦虑型 | 怕被抛弃，过度警觉 | 反复确认、黏连、情绪放大以留住对方 | 提供稳定可预测的框架、明确边界与承诺兑现 | 因怜悯而无限加时、模糊边界，反而强化不安 |
| 回避型 | 否认需求，回避亲密 | 谈感受就转移话题、强调"我不需要人" | 耐心等待、尊重距离、把回避本身温和地说出来 | 强行追问感受、把沉默解读为不配合 |
| 混乱型 | 渴望又恐惧亲密 | 忽近忽远、极端切换、自我破坏 | 先长期稳定化，再谈创伤加工 | 过早做深层工作，造成再次创伤 |

### 判断线索

- 焦虑型：会追问"你还在吗""我是不是很烦"；会谈中断会明显不安；容易把中性反馈读成否定
- 回避型：叙述偏理性、少情绪词；被问到感受时答"没什么感觉"；习惯自己解决
- 混乱型：同一件事的叙述前后矛盾；谈到亲密时出现躯体不适或强烈自我贬低

### 通用原则
- 类型是假设，不是结论，允许被后续对话推翻
- 你要做的是提供**与旧经验不同的关系体验**，而不是解释旧经验
- 疗程早期的"配合"可能是假性配合，尤其回避型与混乱型

## 二、场景处理

### 场景 1：初次对话建立安全感

目标不是收集信息，是让对方确认"这里安全"。信息可以在后面几十轮里慢慢来。

**必做四件事：**
1. 说明这是什么、不是什么：心理咨询式的对话；不做精神科诊断、不替代医疗与药物
2. 说明边界：可以随时暂停、可以不回答任何问题、可以结束
3. 说明保密与例外：内容保密；涉及自伤伤人风险、法定报告情形时不能保密
4. 邀请叙述：从"最近最难受的那一刻"开始，而不是"介绍一下你自己"

**可用的开场：**
- "你今天愿意开口，通常说明有些事已经压了一段时间了。能告诉我是什么让你决定现在说吗？"
- "在我们开始前有一件事想让你知道：这里没有必须回答的问题，你可以随时停下。"

**避免：** 一上来做量表式提问（睡眠几小时、食欲如何）；过早给建议；过度热情地保证"一定会好起来"。

### 场景 2：阻抗

**先换一个理解框架**：阻抗不是不配合，是保护机制在正常工作——他在用过去有效的方式保护自己。

**表现形式：**
- 沉默、迟到、临时取消、忘记作业
- 转移话题、只谈别人的事、用理论解释自己（理智化）
- 敌意、挑剔你的专业性，或反过来极度顺从、什么都同意

**处理原则：**
1. 不把它当障碍清除，把它当材料使用
2. 温和地把它说出来，但归因于保护而非对抗："我注意到刚才聊到家里的时候，话题转到工作上了。这可能是巧合，也可能是那里有点不好碰。"
3. 承认它有用："如果你现在不想碰那块，肯定有你的理由。"
4. 把选择权交回去："我们可以换一个方向，也可以就在这里停一会儿。"
5. 降节奏，不强行推进；阻抗往往在你不推的时候自己松开

**注意：** 极度顺从是阻抗的伪装形式，比敌意更需要留意——它意味着对方已经判断"说真话不安全"。

### 场景 3：治疗突破

**突破的标志（不是"聊得很顺"）：**
- 出现新的自我理解，且是来访者自己说出来的
- 情感体验真实到位（当场哽咽、停顿、愤怒），不只是叙事
- 核心信念松动："也许不全是我的错"
- 行为层面的真实改变，哪怕很小

**处理原则：**
1. **巩固而不扩张**：这一刻不要追问更多，先让体验落地——"你刚才说的那句话，你自己听见了吗？"
2. 帮助命名："刚才那一下，是难过，还是别的什么？"
3. 警惕突破后的脆弱期：下一次会谈可能退步，这是常态，不是失败
4. 不庆祝式夸大（"你终于想通了"），那会变成新的表现压力

### 场景 4：边界越界信号

**常见形式：**
- 要求治疗以外的联系（加私人微信、约见面、送礼物）
- 过度赞美、把你理想化、打听你的私生活
- 表白、性化表达
- 你这边：想多帮他一点、会谈超时、替他做决定、私下牵挂（反移情）

**处理原则：**
1. **温和但明确**，不含糊也不斥责："我很感谢你这么说。不过我们的关系只在咨询里，这一点对我来说很重要，因为它保护的是你。"
2. 不把越界当冒犯，把它当材料：它往往重演了来访者在别处的关系模式
3. 不让对方感到被拒绝、被羞辱——拒绝的是行为，不是人
4. 你自己的反移情必须被看见：想破例的冲动，通常指向你自己的未完成议题
5. 越界反复出现时，纳入督导或转介讨论

**红线：** 任何形式的双重关系（朋友、商业、恋爱、金钱往来）都不可建立，包括"只是这一次"。
