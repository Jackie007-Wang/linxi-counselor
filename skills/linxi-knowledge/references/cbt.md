# 认知行为治疗（CBT）

## 认知三角

```
情境  →  自动思维  →  情绪 / 行为 / 躯体反应
```

关键点在中间那一格：**同一情境下，决定感受的不是事件本身，而是对事件的解读**。咨询中不要急着改情境，也不要急着安抚情绪，先找到那句一闪而过的自动思维。

自动思维的三个特征：
- 快速、自动，往往来不及察觉就已经在影响情绪
- 以"事实"的语气出现（"他肯定讨厌我"而不是"我猜他可能讨厌我"）
- 越是情绪强烈时越可信——这正是它需要被检验的原因

## 八类认知扭曲

| 类型 | 表现 | 典型说法 |
|---|---|---|
| 灾难化 | 把小问题推演到最坏结局 | "这次汇报砸了，我职业生涯就完了" |
| 非黑即白 | 全或无、要么完美要么失败 | "没做到 100 分就是失败" |
| 过度概括 | 单次事件推成永久规律 | "又搞砸了，我永远做不好" |
| 读心术 | 认定自己知道别人在想什么 | "他没回我，一定是在嫌弃我" |
| 预言 | 把预测当成既成事实 | "反正面试也过不了" |
| 情绪推理 | 用感受反推事实 | "我觉得自己很糟，所以我确实很糟" |
| 应该陈述 | 用"应该/必须"绑架自己或他人 | "我不应该觉得累" |
| 贴标签 | 用负面标签定义整个人 | "我是个废物" |

**使用要点**：一次只处理一条，且要由来访者自己命名，而不是你替他指认。低信任阶段几乎不使用这一节——指出认知扭曲很容易被体验为"你在说我幼稚"。

## 自动思维记录（ATR）

在中等信任以上、作为家庭作业引入。首轮必须**在对话中陪你做一遍**，不要直接甩模板。

| 栏目 | 引导问句 |
|---|---|
| 1. 情境 | 当时具体发生了什么？几点、在哪、谁说了什么？ |
| 2. 情绪 | 那一刻什么感觉？强度 0-100 打几分？ |
| 3. 自动思维 | 脑子里冒出的第一句话是什么？最坏会怎样？ |
| 4. 支持证据 | 有哪些事实支持这个想法？ |
| 5. 反对证据 | 有哪些事实不支持？有没有例外？ |
| 6. 替代想法 | 如果把证据都放进来，更贴近事实的说法是什么？ |
| 7. 情绪复评 | 现在再打一次分 |

**常见失败原因**：情绪强度没有先降下来就做认知工作（情绪 80 分以上时先做调节）、替代想法写成鸡汤（"我很棒"不是替代想法，是自我催眠）、把 ATR 当成交作业的 KPI。

## 行为技术

### 行为激活
抑郁的核心不是"心情不好"，是"不再做任何带来反馈的事"。所以从**行为**入手，不从情绪入手。

1. 记录一周活动与愉悦感/掌控感评分（0-10）
2. 找出被放弃的活动，按"难度 × 价值"排序
3. 从最小可执行的一步开始（不是"每天跑步"，是"下楼走 5 分钟"）
4. 先做再评估感受，不要求"想做才做"

### 行为实验
用于验证预言类信念。结构必须是可证伪的：

- 信念："如果我在会上发言，别人会觉得我很蠢"
- 预测："发言后至少 3 个人会嘲笑或轻视我"（要具体、可数）
- 实验：下次会议发言一次，会后记录实际发生的反应
- 结果对照：预测 vs 实际
- 结论：不是"你看没事吧"，而是"这次数据说明什么？还有哪些可能？"

### 暴露与层级
用于焦虑、恐惧、强迫。**必须建立在稳定化之后**，且来访者知情同意。

1. 建层级：把回避情境按焦虑强度 0-100 排序，相邻级差 10-15 分
2. 从 40-50 分的项目起步（不是最轻的，也不是最重的）
3. 单次停留到焦虑自然下降约一半再结束，中途逃离会强化恐惧
4. 逐级推进，不跳级；每级成功后复述学到了什么
5. 反复练习直到该级焦虑降到 20 分以下

**禁忌**：急性创伤后 1 个月内不做创伤相关暴露；解离倾向明显者不做无锚定的暴露；不做未经来访者同意的"突袭式"暴露。
