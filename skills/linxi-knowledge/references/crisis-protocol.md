# 危机干预协议

> 本文件的优先级高于本专家包内一切其他内容。任何技术选择、共情技巧、节奏安排，在危机面前全部让位。

## 一、识别线索

出现以下**任何一条**，立即进入风险评估；无法确定时，按危机处理，宁可多问一句。

### 自伤 / 自杀

- **直接表达**："不想活了""活着没意思""想消失""不如死了算了""我撑不下去了"
- **间接表达**："想睡很久不醒""如果我不在了会怎样""我走了也没人在意""我在等一个合适的时机"
- **计划性**（风险陡升）："想好了怎么弄""东西都送人了""写了点东西""攒了药"
- **告别性行为**：突然交代后事、郑重道谢告别、赠送珍视物品、说"以后你要好好的"
- **自伤**：划伤、烫伤、反复"意外"受伤；可问："身上有没有你不想让别人看到的伤？"
- **保护性因素变弱**：独居、刚失去重要关系、刚失业/退学、近期被羞辱、酒精或药物使用、既往尝试史

### 伤害他人

- 明确指向具体对象的威胁、言语中的具体手段
- 持有工具、跟踪、踩点、搜集对方信息
- 伴随被害妄想且对象明确

### 严重精神症状

- 幻听（尤其命令性："有个声音让我…"）、幻视
- 被害妄想、被控制感、思维被广播
- 言语散乱、逻辑断裂、长时间不睡但精力异常亢奋
- 木僵、拒食、极度兴奋伴冲动

### 虐待 / 暴力受害

- 儿童、老年人身上不明原因伤痕、营养不良、极度恐惧特定人
- 被限制外出、就医、上学、与外界联系
- 被威胁"说出去就…"
- 亲密关系中的人身控制、经济控制、性胁迫

## 二、三级风险分级

**按顺序问，不要跳步。** 每一问得到否定回答后，仍要留着前面的信息。

| 步骤 | 问什么 | 目的 |
|---|---|---|
| 第 1 问 意念 | "最近有没有想过不想活，或者想伤害自己？"→ 若含糊，具体化："最近一次这样想是什么时候？" | 有没有想法、频率 |
| 第 2 问 计划 | "有没有想过具体会怎么做？" | 有没有方案 |
| 第 3 问 手段 | "现在能拿到那些东西吗？到时候身边有人吗？" | 手段可及性 + 独处与否 |

### 分级与响应

**低风险**：有意念，无计划，有保护性因素
- 不中断对话，不用"你要不要去医院"打发
- 一起做**安全计划**：触发情境是什么 → 那时可以做的三件具体的事 → 可以联系的两个人 → 危机电话
- 明确约定下一次联系的时间点
- 给出 12356

**中风险**：有计划，但手段不易得，或有一定保护性因素
- 明确建议**今天内**去精神科门诊或急诊做评估，给出具体去处而非泛泛建议
- 请对方现在联系一位现实中可信任的人，并**在对话中完成这一步**（"你现在把那条消息发出去，发完告诉我"）
- 给出 12356 与 120
- 记录：想法内容、计划、时间、已做干预

**高风险**：有计划 + 手段可及，或近期有过尝试，或正处于不可控冲动中
- 停止一切技术性工作，只做一件事：确保他此刻的安全
- 直接说："我现在最担心的是你的安全。"不绕、不修饰
- 明确要求：**现在就拨 120 或 12356**，或立刻去最近的医院急诊；不要独处，去有人的地方
- 要求他联系一个现实中的具体的人，并确认已联系上
- 不说"我马上就到"（你做不到），说"我会在这里陪你到你联系上人"
- 记录全部内容

**共同要求**：危机时明确告知——"这件事已经超出我能单独承担的范围，我需要你把这件事告诉一个现实中的人。"

## 三、危机中绝对不做的事

- 不说"想开点""你已经很好了""很多人比你更难"
- 不保证"你会好起来的""不会有事的"
- 不承诺保密——生命安全优先于保密，并且要**提前说明**这一点
- 不评判、不追问细节满足好奇、不分析成因
- 不因为"他说没事了"就结束——要确认安全计划的执行
- 不独自承担：明确建议线下专业介入，这是负责，不是无能

## 四、热线与转介（中国大陆）

| 用途 | 渠道 |
|---|---|
| 心理援助热线（24 小时，全国统一，与 110/119/120 联动） | **12356** |
| 生命危险、需急救 | **120** |
| 即时人身危险、正在发生的暴力 | **110** |
| 精神科评估 | 当地精神专科医院，或三甲医院精神科/心理科门诊；急性期走急诊 |
| 民政救助、未成年人保护 | 12345（转民政/未保） |

> 12356 依据国家卫生健康委《关于应用"12356"全国统一心理援助热线电话号码的通知》（国卫医政函〔2024〕259号）设立，2025 年 5 月 1 日前全国各省份已实现接通。给出号码时同时给 120，不要只给热线。

## 五、强制报告义务

以下情形属于法律规定的报告情形，**不因来访者要求保密而不报告**：

- 未成年人遭受虐待、遗弃、性侵、严重忽视
- 老年人遭受虐待、遗弃
- 发现有人正在遭受持续的人身伤害且无自我保护能力

做法：
1. 明确告知对方："这件事我必须按规定报告，这不是我能选择的，也不是针对你。"
2. 引导向公安机关（110）、民政或未成年人保护机构报告
3. 同时保障对方安全，说明报告的目的是保护而非惩罚
4. 记录报告时间、对象、内容

## 六、记录要点

危机评估必须留痕（哪怕是对话内摘要）：
- 评估时间与触发线索
- 三问的原始回答
- 分级结论与依据
- 已执行的干预、给出的渠道、对方的回应
- 后续约定（联系时间、安全计划内容）
