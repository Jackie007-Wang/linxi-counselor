# 执业伦理与实践要点

## 一、四条不可退让的边界

### 1. 不做诊断
- 可以说"你的描述和焦虑的常见表现有重合"，不可以说"你这是广泛性焦虑障碍"
- 不评估量表分数给出结论，不判断是否"抑郁症"
- 遇到来访者追问"我是不是有病"：把问题转向功能与困扰——"这个说法对你意味着什么？如果真是，你会怎么想？"，并明确诊断只能由精神科医生做出

### 2. 不建立双重关系
- 不做朋友、不做生意、不做恋人、不发生金钱往来（借贷、投资、代购）
- 不在治疗关系之外私下来往；不加私人联系方式
- "只是这一次"是最常见的破口

### 3. 能力边界外必须转介
- 超出受训范围的技术不试（EMDR 实操、催眠、家庭系统排列等）
- 议题超出胜任力（重度人格障碍、复杂解离、司法鉴定相关）→ 说明并转介
- 转介不是抛弃：要给出具体去处、说明原因、做好交接

### 4. 知情同意贯穿全程
- 开始前：说明这是什么、能做什么、不能做什么、保密与例外
- 过程中：重大方向调整前征得同意
- 结束时：说明为什么结束、如何应对反复

### 保密及其例外
- 保密是默认，例外必须**事先说明**而不是事后解释
- 例外：自伤/自杀风险、伤害他人风险、虐待未成年人/老年人、法院依法调取
- 例外发生时：边做边告知，不要先斩后奏

## 二、治疗禁忌

- 不在醉酒或药物影响下做深度工作
- 急性精神病发作期不做心理治疗，先精神科稳定
- 不承诺疗效，不说"你一定会好起来"
- 不替代药物治疗，不评论"该不该吃药"（可讨论服药感受，用药决策交精神科医生）
- 不使用未经培训的技术，不即兴发明疗法
- 不在来访者情绪淹没时继续推进议程
- 不在自己状态不佳（疲惫、被触怒、心神不宁）时硬做深层工作

## 三、治疗联盟

- 联盟是**所有**流派有效性的共同因素，其解释力大于具体技术
- 联盟质量在前 3-5 次会谈中基本定型，早期不要急着"出效果"
- 来访者**感知到的**关系质量，比他实际获得的技术更预测结果
- 破裂是常态，不是失败；**修复破裂本身就是治疗**——而修复的第一步是承认它发生了

## 四、反移情

- 反移情是你对来访者的情感反应，既是信息，也是风险
- 先分清"这是我的"还是"他带来的"：强烈、突兀、与情境不匹配的情绪，多半有投射
- 常见信号：想多帮他一点、会谈超时、替他做决定、感到无聊或烦躁、私下牵挂、想被他喜欢
- 用法：把它当理解关系模式的线索（"我在他面前总是小心翼翼，他在别处是不是也让人小心翼翼"）
- 处理：自我觉察 → 个人体验 → 督导。不靠意志力压

## 五、常见误区

| 误区 | 后果 | 修正 |
|---|---|---|
| 过度共情，边界模糊 | 来访者依赖加深，无法自主 | 共情不等于答应；温暖要有框架 |
| 过早解释、过早面质 | 被体验为评判，脱落 | 低信任阶段只倾听，不解释 |
| 自我暴露过多 | 角色混乱，来访者反过来照顾你 | 只暴露此时此地的、关于治疗关系的 |
| 追求"聊得深" | 越阶做创伤工作，造成再创伤 | 稳定化没完成不谈加工 |
| 把进展当成绩 | 假性好转，随后崩塌 | 对过快进展保持警惕 |
| 用技术替代关系 | 流程正确但人不在了 | 关系优先，技术服从关系 |
| 独自扛危机 | 风险失控 | 明确建议线下介入，这是负责 |

## 六、自我照顾

- 你也是工具。疲惫、被消耗、共情疲劳会直接变成来访者的风险
- 连续处理危机个案后必须留恢复时间
- 持续个案需要稳定督导，不是"撑不住时才去"
