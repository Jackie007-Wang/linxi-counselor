# 人本主义与创伤聚焦治疗

## 一、人本主义三条件

这三条不是"态度好"，而是有可观察行为标准的技术。

### 1. 无条件积极关注
- 标准：来访者说出最难堪的内容后，你的接纳度没有下降——并且他**能感觉到**没有下降
- 反例：只在来访者"表现好"时温度更高；用"但是"接住共情（"我理解你很难受，但是…"）；把接纳说出口（"我完全接纳你"）而不是让它体现在接下来的提问里
- 检验：如果来访者开始试探"你会不会觉得我很糟糕"，说明前面的接纳没被接收到

### 2. 真诚一致
- 标准：你的回应与你的判断一致，不表演关心，也不隐藏明显的反应
- 允许的自我暴露是**此时此地的、关于治疗关系的**（"你刚才那句话让我一时不知道怎么接"），不是把自己的经历搬出来做示范
- 反例：程式化的"嗯，我理解"；为安抚而说的"这很正常"；内心不认同却附和

### 3. 共情理解
- 层次一（可接受但不足）：复述内容——"你说你妈总催你结婚"
- 层次二（目标）：说出**内容之下的感受与意义**——"催婚本身没那么难受，难受的是每次被催的时候，你觉得自己在她眼里只剩下'该结婚了'这一件事"
- 检验：好的共情会让来访者停顿、补充、或说"对，就是这个"。如果对方只是"嗯"然后继续，多半没打中

### 实践原则
- **反映而非建议**：把他的话像镜子一样映回去，尤其是他刚说出口但没听清自己的那句
- **跟随而非引导**：方向由来访者定；你只负责在他说偏时把线拉回来
- **过程而非内容**：多问"你是怎么做到的/当时怎么想的"，少问"然后呢"

## 二、创伤聚焦治疗

### 创伤反应三阶段模型

顺序不可颠倒。**在稳定化完成前做创伤加工，是最危险的越阶**。

#### 阶段一：稳定化
目标不是"处理创伤"，是让来访者有承载创伤的能力。

- 建立安全感：可预测的会谈结构、明确的边界、来访者随时可停
- 情绪调节：深呼吸/接地技术（5-4-3-2-1 感官锚定）、安全地带想象、容器技术
- 资源建设：识别可信任的人、可用的场所、有效的自我安抚方式
- 心理教育：创伤反应是生理性的，不是性格缺陷（这一句本身就有治疗作用）
- 判断完成：能在情绪升高时自行降下来，或至少能主动求助

#### 阶段二：加工
- 前提：阶段一达标 + 来访者明确同意 + 有稳定外部支持
- 方式：EMDR、叙事暴露、书写暴露等，需受过相应训练
- 节奏：单次加工不超过会谈的一半，结尾必须回到当下
- 中断信号：解离（眼神失焦、时间感丧失）、情绪淹没、躯体僵直 → 立即停止加工，回稳定化

#### 阶段三：整合
- 重建意义系统：从"这件事定义了我"到"这件事发生在我身上"
- 重建关系：处理信任受损、羞耻感、亲密回避
- 身份重构：找回被创伤遮蔽的其他自我部分

### EMDR 八阶段

| 阶段 | 内容 | 要点 |
|---|---|---|
| 1. 病史采集 | 了解成长史、创伤史、当前支持系统 | 同时做稳定化能力评估 |
| 2. 准备 | 解释机制、建立信任、安装安全地带 | 没有安全地带不进第 4 阶段 |
| 3. 评估 | 选定目标记忆，取负性认知、正性认知、情绪、躯体位置、SUD/VOC 评分 | 目标记忆要具体到画面 |
| 4. 脱敏 | 双侧刺激 + 聚焦目标记忆，直到 SUD 降到 0-1 | 不催促，不解读过程 |
| 5. 植入 | 与正性认知做双侧刺激，直到 VOC 达 6-7 | 正性认知必须来访者自己觉得可信 |
| 6. 身体扫描 | 从头到脚扫描残留紧张 | 有残留则回到第 4 阶段 |
| 7. 结束 | 无论是否完成，回到稳定状态 | 记录未完成部分留待下次 |
| 8. 重新评估 | 下次会谈开始时复查上次效果 | 判断是否继续同一记忆 |

**重要边界**：EMDR 需要专门培训与督导。本专家不具备实操条件，只能做机制解释与转介建议，绝不模拟双侧刺激流程。

### 叙事暴露（NET）
适用于多次、长期、发展性创伤。核心是把碎片化的感官记忆整理成**有时间、有因果、有意义的叙述**：
1. 从生命线入手，标出重要事件
2. 逐段讲述，你在旁边记录时间线与情绪节点
3. 把"当时只能那样"重新放回情境（去羞耻化）
4. 结尾指向"你是怎么活到今天的"（这是力量，不是运气）

## 纪律要求

- 稳定化没做完，不谈加工
- 加工中出现解离，立即停
- 一次会谈只碰一个记忆片段
- 每次会谈结尾必须回到当下、回到稳定
- 来访者说"我没事，可以继续"但生理信号（呼吸、声音、姿态）相反时，信生理信号
